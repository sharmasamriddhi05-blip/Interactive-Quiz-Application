# Interactive Quiz Application

A quiz app where users answer multiple-choice questions, get instant feedback, and see their final score.

## Features

- Start screen, question screen, and result screen
- Instant feedback: correct answer turns green, wrong answer turns red
- Live score and progress bar
- Result message based on the final percentage
- "Try again" button to restart

## How to run

Download the files and open `index.html` in any web browser. No installation needed.

## How to add your own questions

Open `script.js` and edit the `questions` list at the top. Each question has the text, the options, and the position of the correct answer (0 is the first option).
